# Transputer Revival

Transputer Revival is an independent educational and open-engineering portal for learning about Transputer architecture, preserving primary technical knowledge, and documenting measured modern experiments.

The project is static-first and built with Astro. It does not claim institutional endorsement, and unfinished experiments are presented with their evidence status.

## Local development

```sh
npm install
npm run dev
npm run check
npm run build
```

The generated static site is written to `dist/`. Licensing for code, content, and future hardware artifacts is being defined separately.
